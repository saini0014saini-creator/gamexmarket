**GameXMarket** is a modern, responsive gaming account marketplace frontend designed specifically for the **Indian gaming ecosystem**. It allows gamers to buy, sell, and inspect gaming profiles for major mobile titles with guaranteed **Escrow Protection** and **100% Indian Rupee (₹ INR)** pricing.

---

## 🚀 Key Highlights

- **100% Indian Rupees (₹ INR):** All account prices, wallet balances, fees, discounts, and order amounts are strictly displayed in Indian Rupees (₹).
- **Supported Games:**
  - 🏰 **Clash of Clans** (Town Hall 13 - 16, Max Heroes, Supercell ID)
  - 🔥 **Free Fire MAX** (Evo Guns, Yellow/Red Criminal Bundles, Grandmaster)
  - 🎯 **PUBG Mobile / BGMI** (Glacier M416 Lv7 Max, Pharaoh X-Suits, Conqueror)
  - 🔫 **Call of Duty Mobile** (Mythic M13, Damascus camos, Legendary Ghost)
- **Indian Payment Methods:** Instant UPI (Google Pay, PhonePe, Paytm, BHIM, Cred), RuPay / Debit / Credit Cards, and Net Banking across 50+ Indian banks.
- **Escrow Safeguards:** Funds are locked in escrow until the buyer tests login credentials and updates security recovery info.
- **Interactive Role Switcher:** Switch between **Buyer**, **Seller**, and **Admin Panel** with 1 click in the top bar.

---

## 📄 Complete Pages Included

1. **Homepage:** Hero search, popular game categories, featured accounts, trending profiles, festive deals banner, 4-step escrow guide, Indian customer reviews, FAQ accordion, and footer.
2. **Buy Accounts Marketplace:** Category tabs, search, price range filter (₹ INR), minimum level filter, verified sellers toggle, instant delivery filter, and sorting.
3. **Gaming Account Details:** Multi-screenshot viewer, specs grid, seller rating & location, "Buy Now" escrow trigger, "Contact Seller" modal, and related recommendations.
4. **Sell Gaming Accounts:** Multi-step listing wizard with live card preview, 8% platform commission calculator, and "My Submitted Listings" tracking.
5. **User Dashboard:** Left sidebar, stats cards in ₹ INR, interactive monthly sales & volume SVG chart, recent order credentials shortcut, and profile settings.
6. **Wallet & Indian Payments:** Real-time ₹ balance, simulated "Add Money" modal, "Withdraw to Bank/UPI" modal, and transaction ledger.
7. **My Orders Vault:** Orders listing with status filters, encrypted credentials modal (masked password reveal, 2FA codes, handover notes), and simulated GST invoice receipt download.
8. **Admin Operations Panel:** Pending Approvals queue with 1-click "Approve & Publish" or "Reject", user directory, and platform commission slider (default 8%).
9. **Authentication:** Login, Register, mobile OTP verification modal, and 1-click Demo logins for Buyer, Seller, and Admin.
10. **Customer Support:** Ticket submission, WhatsApp Support (`+91 98765 43210`), support email, and emergency escrow fraud escalation.
11. **About Us:** Mission, Vision, and core pillars of trust in Indian gaming.
12. **Legal & Compliance:** Terms & Conditions, Privacy Policy, Refund Policy, Seller/Buyer Guidelines, Dispute Resolution, and Game Publisher TOS Notice.

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/<your-username>/gamexmarket.git

# Navigate to project directory
cd gamexmarket

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
